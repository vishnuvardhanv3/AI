# Model file

Download the official OpenCV Haar Cascade XML and save it in this folder as:

`haarcascade_frontalface_default.xml`

Official source:
https://github.com/opencv/opencv/raw/4.x/data/haarcascades/haarcascade_frontalface_default.xml

The recognition model (`database/face_model.yml`) is generated locally after registering people and running `python src/train.py`. Do not commit personal biometric data or trained personal models to a public repository.
